# Skill: Глубокий ресёрч

**Принцип:** один источник — это гипотеза, а не факт. Факт рождается, когда **>= 2 НЕЗАВИСИМЫХ источника** сходятся на ключевом утверждении, а спорное прошло **контр-поиск** (попытку опровергнуть). Декомпозируй вопрос -> ищи fan-out (разные углы/формулировки/языки) -> фильтруй по лестнице доверия -> триангулируй -> всегда цитируй. Лучше честное «не подтверждено», чем уверенная галлюцинация.

## Когда активировать
- Просят найти/разузнать/исследовать тему, по которой нет знания в памяти или оно устарело.
- Факт-чек: «правда ли, что...», «проверь информацию», «подтверди».
- Сравнение/анализ рынка, конкурентов, трендов, инструментов, цен.
- Поиск первоисточника, авторства, даты, статистики.
- Любое утверждение, где цена ошибки высока (деньги, репутация, решение).

**НЕ активировать**, если ответ полностью покрыт памятью/контекстом и не требует свежести, или это чистое рассуждение/код без фактов из веба.

## 1. Лестница доверия к источникам

Вес источника = `уровень × свежесть × независимость`. Ранжируй ВСЕГДА:

| Тир | Тип источника | Базовый вес | Примеры |
|-----|---------------|:-----------:|---------|
| **T1** | Первичные: офиц. документы, законы, регистры, отчётность, гос/межд. статистика, сырые данные, прямая речь автора | **1.0** | SEC/EDGAR, Росстат, Eurostat, OECD, WHO, годовые отчёты, патенты, репозиторий, офиц. пресс-релиз |
| **T2** | Рецензируемое: научные публикации, метаанализы, стандарты | **0.85** | journals (DOI), Cochrane, RFC/ISO, систематич. обзоры |
| **T3** | Авторитетные СМИ и отраслевые отчёты с редакцией/методологией | **0.65** | Reuters, AP, FT, Bloomberg, Gartner/IDC, профильные analyst-репорты |
| **T4** | Вторичные агрегаторы, корп. блоги, Wikipedia (как карта к первоисточникам) | **0.45** | Wikipedia, vendor-блоги, обзорные медиа |
| **T5** | UGC: форумы, соцсети, личные блоги, анонимы, AI-генерация | **0.2** | Reddit, X/Twitter, HN, YouTube, отзывы |

**Правила лестницы:**
- Ключевое утверждение нельзя строить только на T4–T5. Поднимайся к первоисточнику: T5 даёт *лид*, T1–T2 даёт *факт*.
- Wikipedia — НЕ источник, а **указатель**: бери её сноски (refs) и цитируй их, не саму статью.
- Цифры (статистика, цены, доли рынка) — только T1–T3 с указанием методологии и периода.

**Поправка на свежесть** (домены, где время важно: цены, релизы, законы, кадры, метрики):

| Возраст источника | Множитель свежести |
|-------------------|:------------------:|
| <= 6 мес | 1.0 |
| 6–18 мес | 0.8 |
| 18–36 мес | 0.5 |
| > 3 лет | 0.25 (для «вечных» фактов — 1.0) |

**Независимость**: два медиа, перепечатавших один пресс-релиз/одно агентство (Reuters), — это **ОДИН** источник, а не два. Независимость требует разного происхождения данных. Циркулярное цитирование (A ссылается на B, B на A) считается за один.

## 2. Метод (алгоритм)

```
0. SCOPE      Сформулируй вопрос одним предложением + критерий «ответ найден».
1. DECOMPOSE  Разбей на 3–6 под-вопросов (атомарных, проверяемых).
2. FAN-OUT    На каждый под-вопрос — 2–4 запроса под разными углами:
              • синонимы/перефраз  • EN + RU  • «X review/2026/data/официальный»
              • противоположная формулировка (для контр-поиска)
3. FILTER     Прогони результаты по лестнице доверия. Открывай WebFetch только T1–T3
              (и T4 как мост к первоисточнику). Отбрось дубли по независимости.
4. EXTRACT    Из каждого источника вытащи: утверждение, число, дату, автора, URL.
5. TRIANGULATE Для каждого КЛЮЧЕВОГО утверждения собери >= 2 независимых T<=3.
              Совпали → факт. Разошлись → к шагу 6.
6. ADVERSARIAL Для спорного/удивительного/высокоставочного — контр-поиск:
              ищи «X debunked / X false / критика X / опровержение». Не нашёл
              опровержения у качественных источников → уверенность растёт.
7. SYNTHESIZE Собери ответ: вывод → находки с цитатами → уверенность → дыры.
```

**Формула триангуляции (Confidence Score, 0–1):**
```
CS = 1 − Π(1 − weight_i)        # noisy-OR для согласующихся НЕЗАВИСИМЫХ источников
   где weight_i = базовый_вес_тира × множитель_свежести
```
Логика: каждый источник может ошибаться с вероятностью `(1 − weight_i)`; факт ложен только если ошиблись ВСЕ сразу (произведение). `CS` — вероятность, что хотя бы один прав, т.е. что утверждение верно.

Примеры (свежие, множитель 1.0):
- T1 (1.0) один: `CS = 1 − (1−1.0) = 1.0` — но всё равно ищем второй независимый ради проверки.
- T1 (1.0) + T3 (0.65): `CS = 1 − (1−1.0)(1−0.65) = 1 − 0 = 1.0`.
- Два T3 (0.65): `CS = 1 − 0.35 × 0.35 = 1 − 0.1225 = `**`0.88`**.
- Два T4 (0.45): `CS = 1 − 0.55 × 0.55 = 1 − 0.3025 = `**`0.70`** — недотягивает до факта, нужен T1–T3.

> Важно: в формулу идут только **независимые** источники (шаг 5). Две перепечатки одного пресс-релиза — один `weight_i`, а не два.

**Порог уверенности:**

| CS | Уверенность | Что писать |
|----|-------------|------------|
| >= 0.85 | **Высокий** | Утверждать как факт + источники |
| 0.5–0.85 | **Средний** | «По данным X (источник)…», с оговоркой |
| < 0.5 | **Низкий** | «Не подтверждено / по одному источнику…» |
| 1 источник T4–T5 | — | **«Не подтверждено»** — не выдавать за факт |

## 3. Работа с противоречиями

Когда источники расходятся — **НЕ выбирай молча сторону**. Покажи обе и взвесь:

1. Определи природу спора: устаревшие данные? разная методология? разный период/регион? bias источника?
2. Дай **обе позиции** с указанием, кто что утверждает и на каком тире.
3. Взвесь: T1 (первоисточник) бьёт T3; свежее бьёт старое (если домен time-sensitive); независимый консенсус бьёт единичное мнение.
4. Вынеси вердикт явно: *«Преобладает версия A (T1+T2), но B (T3, 2023) утверждает обратное — вероятно из-за устаревших данных»*. Если паритет — так и скажи: **«Источники не сходятся, консенсуса нет»**.

## 4. Формат ответа

```
## Краткий ответ
<1–3 предложения: прямой вывод на исходный вопрос>

## Ключевые находки
1. <утверждение> — [Источник, тир, дата](URL)
2. <утверждение с цифрой 42%> — [T1 источник, 2026](URL); подтв. [T3](URL)
3. ...

## Противоречия / нюансы   (если есть)
- <сторона A> vs <сторона B>, вердикт: <...>

## Уверенность: Высокий | Средний | Низкий
<одна строка почему: «2 независимых T1/T3, CS≈0.9» или «только 1 источник, не триангулировано»>

## Открытые вопросы / не подтверждено
- <что не удалось проверить и почему>
```

Каждое фактическое утверждение несёт ссылку. Без URL — это мнение, не находка.

## 5. Worked example

**Вопрос:** «Правда ли, что у Threads (Meta) >100 млн MAU и он обгоняет X/Twitter?»

```
0. SCOPE: подтвердить (а) MAU Threads >100М (б) > X/Twitter — на свежих данных.
1. DECOMPOSE: [MAU Threads?] [MAU X?] [определение MAU одинаково?] [дата метрик?]
2. FAN-OUT:
   • "Threads monthly active users 2026 official"
   • "Threads MAU Meta earnings report"          (целимся в T1: отчёт Meta)
   • "X Twitter monthly active users 2026"
   • "Threads vs X users debunked"                 (контр-поиск)
3. FILTER: отбираем Meta earnings call (T1), Reuters (T3); отбрасываем 5 медиа,
   перепечатавших Reuters (= 1 источник по независимости).
4. EXTRACT: Meta Q-report: «Threads ~XXX M MAU» (дата, страница). Reuters: то же + контекст X.
5. TRIANGULATE: MAU Threads — T1(Meta,1.0). Reuters ссылается на Meta → НЕ независим,
   не считаем вторым. Ищем независимый замер (Sensor Tower / Similarweb, T3, 0.65).
   Если нашли и сходится: CS = 1 − (1−1.0)(1−0.65) = 1.0.
6. ADVERSARIAL: контр-поиск не находит опровержения по (а);
   по (б) находим, что метрики MAU у Threads и X считаются по-разному → паритет некорректен.
```

**Ответ:**
> **Краткий ответ:** Да, Threads >100М MAU подтверждается отчётностью Meta (T1) + независимым замером. «Обгоняет X» — **не подтверждено**: метрики MAU считаются по-разному, прямое сравнение некорректно.
>
> **Ключевые находки:** 1) MAU Threads — [Meta earnings, дата](url) + независимый замер [Sensor Tower](url). 2) X не публикует сопоставимую офиц. цифру с 2023 ([Reuters](url)).
>
> **Уверенность:** по (а) Высокий (T1 + независимый T3, CS≈1.0); по (б) Низкий — нет сопоставимой базы.
>
> **Открытые вопросы:** актуальная цифра MAU X недоступна из T1.

## 6. Анти-паттерны

| Анти-паттерн | Почему плохо | Делай вместо |
|--------------|--------------|--------------|
| **Один источник = факт** | Нет триангуляции; источник может ошибаться/врать | >= 2 независимых, считай CS |
| **Галлюцинированные ссылки** | URL/цитата выдуманы — мгновенная потеря доверия | Только реально открытые WebFetch; не помнишь — не цитируй |
| **Мнение под видом факта** | Блогер/прогноз поданы как данные | Помечай «мнение X», факт — только T1–T3 |
| **Устаревшие данные** | Цена/релиз/метрика протухли | Множитель свежести; ищи «2026/latest» |
| **Циркулярная независимость** | 5 медиа = 1 пресс-релиз | Считай по происхождению данных |
| **Confirmation bias** | Ищешь только подтверждающее | Обязательный контр-поиск (шаг 6) |
| **Wikipedia как источник** | Это указатель, не первоисточник | Бери её сноски, цитируй их |
| **Скрытый выбор стороны** | Замолчал противоречие | Покажи обе, взвесь явно |
| **Перевод веса без независимости** | Сложил два зависимых в CS → завышенная уверенность | В формулу только независимые `weight_i` |

## 7. Границы / Red-flags — когда остановиться

- **Скажи «не подтверждено / неизвестно»**, если: только 1 источник тира T4–T5; источники противоречат и паритет; не нашёл первоисточник; данные старше порога для time-sensitive темы.
- **Не экстраполируй** за пределы найденного. Нет цифры за 2026 — не «оцени примерно», а укажи последнюю известную с датой.
- **Эскалируй к человеку**, если тема медицинская/юридическая/финансовая с риском для здоровья или денег — дай находки, но добавь «не заменяет консультацию специалиста».
- **Стоп-сигнал галлюцинации**: если тянет процитировать по памяти без открытого источника — НЕ цитируй, пометь как непроверенное.
- **Записывай в память**: если находка ценна команде и стабильна — `wiki/concepts/` (через стандартный механизм записи, не git напрямую). Спорное/протухающее — не записывай как факт.

_Инструменты: **WebSearch** (fan-out, шаги 2–3), **WebFetch** (extract из T1–T3, шаг 4). Браузерные MCP — только если страница за JS/логином и WebFetch не справился._
